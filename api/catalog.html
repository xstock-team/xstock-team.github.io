商品目录 get_catalog

约 617 字大约 2 分钟

拉取当前可售商品列表，用于在你的商城建立或更新商品映射。

  • 权限：catalog.read
  • 幂等：只读
  • 建议频率：启动时全量、之后每 5–15 分钟增量

请求

{
  "action": "get_catalog",
  "schema_ver": "1.0",
  "req_id": "shop-a-20261124-cat-001",
  "data": {
    "page": 1,
    "page_size": 50,
    "updated_since": "2026-11-24T00:00:00Z",
    "category": null
  }
}
字段类型必填说明
pageint否页码，从 1 开始，默认 1
page_sizeint否每页条数，1–100，默认 20
updated_sincestring否只返回该时间之后有变化的商品（RFC 3339），用于增量同步
categorystring否按分类过滤，留空为全部

响应

{
  "req_id": "shop-a-20261124-cat-001",
  "corr_id": "c_7f3a91",
  "schema_ver": "1.0",
  "code": "OK",
  "message": "",
  "data": {
    "page": 1,
    "page_size": 50,
    "total": 128,
    "has_more": true,
    "items": [
      {
        "sku_id": "sku_demo_01",
        "sku_code": "ACC-1001",
        "title": "示例数字账号（月付）",
        "category": "数字账号",
        "summary": "一份一个账号，含账号与密码",
        "unit": "block",
        "min_qty": "1",
        "max_qty": "20",
        "step": "1",
        "price": { "amt": "10.00", "ccy": "CNY" },
        "deliver_kind": "acct_bundle",
        "status": "on_sale",
        "updated_at": "2026-11-24T09:12:00Z"
      }
    ]
  }
}

商品字段

字段类型说明
sku_idstring下单使用的商品标识，稳定不变
sku_codestring你的内部编码参考，可用于映射
titlestring商品名称
categorystring分类名称
summarystring规格简述，如交付形式与包含内容
unitstring销售单位，通常为 block
min_qty / max_qty / stepstring单次下单的最小、最大与递增数量
pricemoney基础供货价（未含等级优惠）
deliver_kindstring交付物类型：acct_bundle secret_code file_asset download_ref
statusstringon_sale / suspended（暂停）/ off_sale（下架）
updated_atstring最近变更时间

使用说明

  • price 是基础价，实际成交价按你的等级优惠计算，以 get_quote 为准。
  • status 不是 on_sale 的商品不要上架销售，即使历史上架过。
  • 增量同步时以 updated_since 为游标，保存本次响应时间作为下次的游标，不要用本地时间。
  • 分页结果可能因数据变化而错位，全量同步建议按 page 顺序拉完并记录 total。

同步建议

场景做法
首次接入全量分页拉取，建立 sku_id → 你的商品 映射
日常同步每 5–15 分钟用 updated_since 拉增量
商品下架按 status 更新为不可售，不要删除本地映射，历史订单仍需展示
首日上线同步完成后再开放下单入口，避免消费者买到未映射商品
