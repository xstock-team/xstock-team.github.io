接入流程

约 951 字大约 3 分钟

从零到第一笔订单，按下面五步走。全程可在分销商门户自助完成，无需等待人工审批的环节会明确标注。

第 1 步：注册并登录门户

在 xstock 分销商门户注册账号并登录。一个账号代表一个经营主体，包含：

  • 登录凭据（仅用于门户登录）
  • 结算币种与联系方式
  • 账户余额与等级
  • 名下可创建多个店铺

账户与店铺的关系

账户负责「钱」，店铺负责「接入」。同一账户下的所有店铺共享余额与等级，但各自有独立的 API Key、Secret、回调地址与接口权限。一个店铺出问题不影响其他店铺。

第 2 步：充值余额

在门户的充值页面提交储值申请并完成支付。余额到账后即可用于下单。

  • 首期按结算币种分区，一个账户同一时间只启用一种结算币种，不自动换汇。
  • 充值到账后账户等级会在下次报价时生效，不需要额外操作。

详见余额与结算。

第 3 步：创建店铺并获取凭据

在门户里新建一个店铺，填写：

配置项说明
店铺名称仅用于门户内区分，不参与接口寻址
商城类型当前支持独角数卡类商城，自建商城选择「自定义接入」
回调地址HTTPS 地址，保存后平台会发起校验，校验通过才会投递事件
接口权限按需勾选，例如商品读取、报价、下单、查单、交付物读取、售后
IP 白名单可选，配置后仅允许白名单地址调用

保存后系统生成一对凭据：

  • API Key：公开标识，随请求头发送。
  • API Secret：仅用于计算签名，只在生成时完整显示一次，请立即保存到服务端配置中。

保管要求

Secret 等同于账户在该店铺的调用权限。不要写入前端代码、仓库、日志或客服文档；怀疑泄露时在门户里立即轮换，新密钥生效后旧密钥按时限失效，历史订单归属不变。

第 4 步：完成回调校验

平台会向你填写的回调地址发送一次校验请求：

  1. 你的服务端校验签名，返回 {"code":"OK"}。
  2. 校验通过后，回调地址才被视为有效。
  3. 修改地址会重新校验，旧地址停止投递。

回调接收端要求：

  • 公网可达，支持 HTTPS，证书有效
  • 5 秒内返回 2xx，业务处理异步化
  • 对同一 event_id 做幂等，重复投递不重复处理

详见回调事件。

第 5 步：联调并上线

建议按以下顺序联调：

  1. get_catalog 拉取商品目录，确认能拿到 SKU。
  2. get_avail 查几个 SKU 的可售数量。
  3. get_quote 取报价，核对金额与币种。
  4. req_order 下一笔小额测试单。
  5. 等待 order.fulfilled 回调，或主动 get_order 查状态。
  6. get_dlv 领取交付物，确认内容完整。
  7. 走一遍 req_cancel（未交付前取消）与 open_case（售后提交）。

全部通过后再切换正式流量。逐项自查见联调验收清单。

常见卡点

现象先检查
401 或签名错误时间戳是否在 5 分钟内、签名串拼接是否含原始请求体摘要
403 无权限该店铺是否勾选了对应接口权限
429是否超过每分钟调用上限，见错误与重试
下单返回余额不足门户余额是否足够冻结本次成交金额
收不到回调回调地址是否通过校验、是否 5 秒内返回 2xx
