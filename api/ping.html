连通性 ping

约 551 字大约 2 分钟

v1 草案

本页属于 v1 接入协约草案，细节可能随接入清单调整，请以门户发布的正式清单为准。

用于接入联调与运行期探活，确认地址、凭据与签名链路是否可用。为兼容 dujiao-next 的连接检测，该命令不消耗业务额度、不改变任何数据。

  • 权限：无需额外权限（仅需店铺有效的 API Key 与签名）
  • 方法：GET
  • 幂等：只读，可高频调用（仍受限流约束）
点开字段可查看类型与说明

正在加载交互式结构…

请求示例

GET /dist/api/v1/ping HTTP/1.1
Host: api.xstock.example
X-Xstock-Api-Key: xs_live_xxxxxxxx
X-Xstock-Timestamp: 1795000000
X-Xstock-Signature: 9f2c1d...
参数说明
无ping 没有业务参数，直接请求路径，不带 ?；cmd 已在路径里

响应中的 id 由平台生成，仅用于排障，请求时不需要传。

响应示例

{
  "id": "probe-20261126-001",
  "cmd": "ping",
  "code": 0,
  "msg": "",
  "data": {
    "pong": true,
    "protocol": "dujiao-next-v1",
    "protocol_ver": "1.0",
    "server_time": "2026-11-26T04:00:00Z",
    "site_name": "xstock 数字供应云服务",
    "balance": { "amt": "520.00", "ccy": "CNY" },
    "member_level": { "code": "gold", "name": { "zh-CN": "黄金等级", "en": "Gold" } }
  },
  "stamp": 1795000000
}

除连通性外，ping 还返回下游展示所需的信息：

字段说明
site_name站点名称，便于下游后台展示
balance当前店铺可用余额（amt + ccy）
member_level账户等级；无等级方案时为空对象

dujiao-next 在保存站点连接时会发起一次连通性检测。本接口按该协议的探测习惯提供：

  • 只做认证与签名校验，不读取业务数据；
  • 不占用商品、订单等接口权限；
  • 返回协议名与版本，便于对方判断适配器是否匹配。

排障顺序

ping 失败时先排这三项：① 地址是否可达；② X-Xstock-Timestamp 与平台时间偏差是否在 300 秒内；③ 签名串是否用原始请求体/查询串计算。ping 通过但业务接口失败，通常是接口权限或业务参数问题。
