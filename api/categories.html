获取商品目录 get_categories

约 542 字大约 2 分钟

返回全部分类目录，用于下游建立分类映射、按分类导入商品，以及在后台展示商品结构。

  • 权限：catalog.read
  • 方法：GET
  • 幂等：只读

v1 草案

本页属于 v1 接入协约草案，细节可能随接入清单调整，请以门户发布的正式清单为准。

点开字段可查看类型与说明

正在加载交互式结构…

目录与清单的区别

get_categories 是分类目录：只有分类层级，不含商品明细。

get_goods 是商品清单：商品 → SKU 的完整数据，商品自带 category_id，可直接与这里返回的分类对应。

请求示例

GET /dist/api/v1/get_categories HTTP/1.1
Host: api.xstock.example
X-Xstock-Api-Key: xs_live_xxxxxxxx
X-Xstock-Timestamp: 1795000000
X-Xstock-Signature: 9f2c1d...

无参数，一次返回全部分类；分类数量通常不大，不需要分页。

使用说明

  • 分类最多两级：parent_id 为 0 表示一级分类，子分类的 parent_id 指向父分类。
  • category_id 是数字标识，guid 是同一分类的 32 位字符串标识（跨店铺、跨版本稳定，适合做持久映射）。name 是多语言映射，thumb 是分类图片地址（无图为空串），default_locale 指明回退语言。goods_count 含子分类下的商品数，可用于后台展示与按分类导入。
  • 分类下架后不再返回；已建立的商品映射不需要删除，get_goods 里对应商品会变成 is_active=false。
  • 与独角数卡的 GET /categories 对应，字段映射见与独角数卡对接。

同步建议

场景做法
首次接入先拉目录建立分类映射，再拉商品清单
日常同步分类变化不频繁，每天拉一次即可
分类加价用 category_id 配置加价规则，商品清单自带该字段
