申请接入

约 598 字大约 2 分钟

想成为 xstock 的分销商，按下面流程提交申请。我们会在收到完整资料后联系你完成开户与联调。

当前信息为占位

本页的联系方式、资质要求与响应时效仍在完善中，正式发布前会替换为最终版本。

申请条件

项目要求
经营主体具备合法经营资质的企业或个体经营者
业务形态自有商城或使用已支持的商城程序（如独角数卡）
结算方式接受预存余额结算，不做信用透支
合规要求承诺不经销违法违规商品，配合平台风控核查

需要准备的材料

  1. 经营主体名称与统一社会信用代码（或对应注册信息）
  2. 联系人姓名、电话、邮箱
  3. 商城地址与所用程序类型（独角数卡 / 自建）
  4. 预计经营的品类与月均采购规模
  5. 结算币种

申请流程

提交资料 → 资质审核（1–3 个工作日）→ 开户 → 创建店铺与凭据 → 联调 → 上线
  1. 提交：按下方联系方式发送资料。
  2. 审核：核对主体资质与经营范围，必要时补充材料。
  3. 开户：创建分销商账户，确认结算币种。
  4. 建店：在门户创建店铺，获取 API Key 与 Secret。
  5. 联调：按接入流程完成 ping、目录、报价、下单、交付全链路。
  6. 上线：联调通过后开放正式交易。

联系方式

渠道信息
商务邮箱待补充（示例：bd@example.com）
客服电话待补充
在线客服待补充
工作时间待补充（示例：工作日 09:00–18:00）

提交时请注明

邮件标题建议为「分销商接入申请 - 公司名称」，正文附上材料清单，便于快速分派。

常见问题

个人可以接入吗？ 需具备合法经营资质，具体以审核结论为准。

审核要多久？ 资料齐全时通常 1–3 个工作日；需要补充材料时会另行通知。

可以先联调再决定吗？ 可以。开通测试店铺后，使用小额余额完成全链路联调，再决定是否正式上线。
