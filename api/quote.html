获取报价 get_quote

约 603 字大约 2 分钟

按商品获取当前单价（已应用等级优惠）。报价就是单价，不存在按数量阶梯让利，因此不需要传数量。

  • 权限：quote.read
  • 方法：POST
  • 幂等：只读，不改任何状态

v1 草案

本页属于 v1 接入协约草案，细节可能随接入清单调整，请以门户发布的正式清单为准。

点开字段可查看类型与说明

正在加载交互式结构…

定位规则

与查询可售一致：

  • 商品：goods_id 与 guid 至少给一个；同时给时以 guid 为准。
  • SKU（可选）：skus 里每个 SKU 用 sku_id 或 guid，guid 优先；省略则报价该商品全部 SKU。

}

字段说明
quote_id报价标识；下单时可带上统一本次单价
base_prices商品级多币种基础单价；无 SKU 的商品按它成交
prices商品级多币种成交单价（已应用等级优惠）
default_ccy商品与 SKU 各带一个的默认币种；prices 中一定包含它
skus[]各 SKU 的 base_prices / prices；无 SKU 时为空数组
checked_at价格采集时间；顶层、商品层、SKU 层各有一个

使用规则

  • 报价不占余额、不锁库存；成交金额按实际下单数量 × 报价单价计算。
  • 报价不设固定有效期；价格调整后重新报价即可，下单金额以当时的报价或商品清单为准。
  • 等级只影响新报价；已成交订单不受后续等级或价格变化影响。
  • 下单数量仍需满足该 SKU 的 min_qty / max_qty / per，见查询可售数量。
