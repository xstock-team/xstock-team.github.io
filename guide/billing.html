余额与结算

约 726 字大约 2 分钟

xstock 采用预存余额、下单冻结、交付扣款的结算方式，不做信用透支。

资金流转

充值到账  →  余额可用
下单受理  →  冻结成交金额（不可用，但未扣）
整单交付  →  解冻并扣款
整单取消  →  解冻，余额恢复可用
售后核定  →  按核定金额退回余额
  • 冻结：订单受理即冻结，防止并发超扣。
  • 扣款：只有整单交付时才扣款。内部配货未完成不影响你的余额可用状态，但也拿不到部分货物。
  • 取消：未交付订单取消后释放冻结，这是解冻，不是退款。
  • 退款：仅售后核定后发生，退回余额，原路可查流水。

余额与店铺

项目归属
余额、充值、等级账户
API Key/Secret、回调地址、接口权限店铺
订单店铺提交，资金走账户余额

同一账户下的店铺共享余额；多家店铺同时下单会按实际可用余额竞争，不会超扣。

等级与优惠

等级按同币种累计有效实付储值净额划分：

  • 充值实际入账增加累计值
  • 该笔充值发生退款、拒付或撤销时扣减
  • 赠送金额不计入等级
  • 订单消费不降低等级，订单退款不视为再次充值

等级只影响新报价：报价时按当前等级计算折扣，成交后金额已冻结，之后等级变化不会改写历史订单金额。

优惠形式为折扣率：例如 pay_ratio = 0.95 表示按基础供货价的 95% 成交。等级优惠不与商城侧其他活动叠加计算，也不改变商品是否可售。

账单与流水

门户中可查看：

  • 当前可用余额与冻结中金额
  • 每笔充值及其到账状态
  • 每笔订单的冻结、扣款、释放、退款流水
  • 按时间段导出对账数据

对账建议

每日比对门户流水的「订单扣款」总额与你商城侧的成交额；发现差异时，以订单号（order_no）为线索逐笔核对，不要只看总额。

常见资金问题

余额够为什么下单仍被拒？ 可能是冻结金额随报价变化、或报价已过期。重新 get_quote 后以新报价下单。

取消后余额为什么没变？ 看的是「可用余额」还是「冻结金额」。取消后冻结释放、可用余额恢复，可用余额数字会变；若订单已扣款，取消不再支持，走售后。

能不能先发货后付款？ 不能。下单即冻结，余额不足会被拒绝。

充错了币种怎么办？ 账户首期只启用一种结算币种，不支持自动换汇。请联系门户客服处理，不要自行用另一币种下单。
