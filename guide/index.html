服务概览

约 603 字大约 2 分钟

xstock 为分销商提供数字商品的供货服务。你在自己的商城里上架商品、接待消费者，xstock 负责商品供给与交付；两端通过一套标准 API 连接。

我们提供什么

能力说明
商品供给数字账号、卡密类等数字商品，按 SKU 供货，一 SKU 一份完整交付物
可售查询查询指定 SKU 的可售数量，便于你在商城展示库存
报价按你的等级优惠计算成交价，报价可锁定短时有效
下单接单提交订单即受理并冻结对应余额，无需人工干预
自动交付整单配齐后一次性交付，交付物可即时领取
售后受理商品质量问题可提交售后工单，由平台核实处理
账户与账单门户内可查看余额、流水、订单与售后进度

不提供什么

为避免误解，先说清边界：

  • 不代收终端消费者款项。消费者的支付、退款与你的商城之间完成，我们不参与。
  • 不提供消费者身份、会员与营销体系。这些属于你的商城。
  • 不做信用透支。下单前账户余额需足够冻结成交金额。
  • 不支持分批交付。一个订单只有「整单交付」或「未交付」两种结果。

两种合作方式

使用已支持的商城程序

我们提供开箱即用的商城适配：在商城后台填写接入地址、API Key 与 Secret 即可完成对接，无需改动代码。适合快速上线。

自建商城自行对接

按 API 参考 自行实现签名、下单、查单与回调。适合有个性化流程的团队，接入前请先完成接入流程中的联调。

接入前需要准备

  • 一个可用于登录分销商门户的账号
  • 结算币种（开户时确认，交易前必须确定）
  • 商城侧可被公网访问的回调地址（HTTPS）
  • 能安全保存 API Secret 的服务端环境（不要放在前端或客户端）
