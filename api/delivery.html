交付物 get_dlv

约 579 字大约 2 分钟

领取已交付订单的交付物。交付物是数字商品的实际内容，可能是账号组合、卡密、文件或下载链接。

  • 权限：delivery.read
  • 幂等：只读，但每次领取都会记录访问审计
  • 前置条件：订单 fulfill_state=full

请求

{
  "action": "get_dlv",
  "schema_ver": "1.0",
  "req_id": "shop-a-20261124-dlv-001",
  "data": {
    "order_no": "XS20261124000123",
    "line_no": 1
  }
}
字段类型必填说明
order_nostring是平台订单号
line_noint否指定订单行；省略则返回全部已交付行

响应

{
  "req_id": "shop-a-20261124-dlv-001",
  "corr_id": "c_7f3a96",
  "schema_ver": "1.0",
  "code": "OK",
  "message": "",
  "data": {
    "order_no": "XS20261124000123",
    "fulfilled_at": "2026-11-24T13:05:48Z",
    "items": [
      {
        "line_no": 1,
        "sku_id": "sku_demo_01",
        "qty": { "value": "2", "unit": "block" },
        "artifacts": [
          {
            "artifact_id": "art_01",
            "kind": "acct_bundle",
            "logical_unit_cnt": 1,
            "content": {
              "username": "demo_user_01",
              "password": "demo_pass_01",
              "note": "首次登录建议修改密码"
            }
          },
          {
            "artifact_id": "art_02",
            "kind": "acct_bundle",
            "logical_unit_cnt": 1,
            "content": {
              "username": "demo_user_02",
              "password": "demo_pass_02"
            }
          }
        ]
      }
    ]
  }
}

交付物结构

字段说明
artifact_id交付物标识，用于售后举证
kindacct_bundle / secret_code / file_asset / download_ref
logical_unit_cnt该交付物包含的商品份数，通常为 1
content直接可读内容，结构随 kind 不同
content_ref大文件或敏感内容返回引用地址，直接内容可能为空
expires_at引用地址的失效时间

各类型字段

kindcontent 结构
acct_bundleusername、password，可能含 email、note、extra
secret_codecode（卡密字符串），可能含 batch
file_assetfile_name、size、content_ref
download_refurl、expires_at

领取规则

  • 只有 fulfill_state=full 的订单能领取，否则返回 PERMANENT / NOT_DELIVERED。
  • 重复领取不会重复扣款，内容一致；但会写入访问审计，便于追溯泄露。
  • 一份交付物对应一个 SKU 单位，不要按内部行数拆分统计数量，数量看订单行 qty。
  • 引用地址可能过期；过期后重新领取即可。

保存与转交

交付物是你对消费者的履约凭据。建议领取后立即加密落库，并按最小必要原则展示。不要把交付物原文写进日志、工单或客服截图。

订单未交付时

场景表现处理
尚未开始NOT_DELIVERED等待回调或查单
配货中NOT_DELIVERED等待，不要重复下单
已取消ORDER_CANCELLED无需领取

错误

code / sub_code场景
PERMANENT / NOT_DELIVERED订单尚未交付
PERMANENT / ORDER_CANCELLED订单已取消
PERMANENT / ORDER_NOT_FOUND订单不属于当前店铺
PERMANENT / SCOPE_DENIED未开通 delivery.read
PERMANENT / ARTIFACT_EXPIRED引用地址过期，重新领取
